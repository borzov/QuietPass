隐私政策

更新日期：2026年11月7日

QuietPass 是由 Maksim Borzov 开发的 Safari 密码生成器，在您的 Mac 上生成新密码。应用不会向开发者传输密码、浏览记录、网站地址或账户名称，也不包含分析、广告或跟踪 SDK。

本地存储与删除

生成设置保存在本地。只有成功复制或插入的密码才会加入历史记录。历史记录保存在本地 macOS 钥匙串中，并按 Safari 配置文件分别存储。QuietPass 不会通过 iCloud 同步历史记录，也不会将其发送到服务器。未使用的生成密码不会被记录。

在设置中，您可以选择不保存历史记录，或保留 1、7、30 或 90 天，默认为 7 天。保留期从使用密码时开始计算。过期记录会在下次访问历史记录时删除。仅打开生成器不会访问历史记录。延长保留期不会恢复过期记录。经扩展内确认后，您可以清空历史记录，或关闭历史记录并删除已有记录。

复制与插入

复制操作会将所选密码放入系统剪贴板。剪贴板访问权限以及可能的系统剪贴板同步由 macOS 和您的设置控制。插入操作仅将所选密码传入当前页面上您选择的可编辑字段。QuietPass 不会提交表单或收集页面内容。

联系支持

当您向支持邮箱发送邮件时，开发者会收到您的电子邮件地址以及您选择提供的信息。这些信息用于回复和解决您的请求，仅在为此目的及履行适用义务所需的时间内保留。有关支持邮件或删除邮件的问题，请联系 max.borzov@me.com。提供支持不需要您发送密码。

本网站

这些页面不包含分析脚本或信息提交表单，托管于 GitHub Pages。GitHub 会出于安全目的记录访客的 IP 地址；其网站数据处理方式见 GitHub 隐私声明。打开扩展不会自动访问本网站。

变更与联系

如果 QuietPass 的数据处理方式发生变化，本政策将相应更新。上方日期标明当前版本。如有隐私问题，请联系 max.borzov@me.com。
