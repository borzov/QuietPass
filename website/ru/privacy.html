Конфиденциальность

Обновлено: 7 ноября 2026 года

QuietPass — генератор паролей для Safari, разработчик — Максим Борзов. Новые пароли создаются на вашем Mac. Приложение не передаёт разработчику пароли, историю посещений, адреса сайтов или имена учётных записей и не содержит SDK аналитики, рекламы или отслеживания.

Локальное хранение и удаление

Параметры генерации сохраняются локально. В историю попадают только успешно скопированные или вставленные пароли. История хранится локально в Связке ключей macOS отдельно для каждого профиля Safari. QuietPass не синхронизирует историю через iCloud и не отправляет её на сервер. Неиспользованные сгенерированные пароли не записываются.

В настройках можно отключить сохранение или выбрать 1, 7, 30 либо 90 дней; по умолчанию — 7 дней. Срок считается от времени использования пароля. Просроченные записи удаляются при следующем обращении к истории. Открытие генератора само по себе не обращается к истории. Увеличение срока не восстанавливает просроченные записи. Историю можно очистить или отключить с удалением записей после подтверждения в расширении.

Копирование и вставка

Копирование помещает выбранный пароль в системный буфер обмена. Доступ к буферу и его возможная системная синхронизация определяются macOS и вашими настройками. Вставка передаёт только выбранный пароль в выбранное вами редактируемое поле текущей страницы. QuietPass не отправляет форму и не собирает содержимое страницы.

Обращения в поддержку

При отправке письма разработчик получает ваш email и сведения, которые вы решили включить. Они используются для ответа и решения вопроса и хранятся лишь столько, сколько необходимо для этой цели и выполнения применимых обязательств. По вопросам обращения или его удаления пишите на max.borzov@me.com. Для поддержки пароли не нужны.

Этот сайт

На этих страницах нет скриптов аналитики и форм отправки данных. Сайт размещён на GitHub Pages. GitHub сохраняет IP-адреса посетителей в целях безопасности; обработка данных сайта описана в политике конфиденциальности GitHub. Открытие расширения не вызывает автоматического посещения этого сайта.

Изменения и контакты

Если способы обработки данных QuietPass изменятся, политика будет обновлена. Дата выше обозначает текущую редакцию. По вопросам конфиденциальности пишите на max.borzov@me.com.
