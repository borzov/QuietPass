Privacidad

Actualización: 7 de noviembre de 2026

QuietPass es un generador de contraseñas para Safari desarrollado por Maksim Borzov. Las nuevas contraseñas se generan en tu Mac. La app no transmite al desarrollador contraseñas, historial de navegación, direcciones de sitios web ni nombres de cuentas. No contiene SDK de análisis, publicidad ni seguimiento.

Almacenamiento local y eliminación

Las preferencias de generación se guardan localmente. Solo las contraseñas copiadas o insertadas correctamente se añaden al historial. El historial se guarda localmente en el llavero de macOS, por separado para cada perfil de Safari. QuietPass no sincroniza el historial mediante iCloud ni lo envía a un servidor. Las contraseñas generadas que no se utilizan no se registran.

En Ajustes puedes desactivar el guardado o elegir 1, 7, 30 o 90 días; el valor predeterminado es 7 días. El plazo empieza cuando utilizas la contraseña. Las entradas caducadas se eliminan la próxima vez que se accede al historial. Abrir el generador por sí solo no accede al historial. Ampliar el plazo no recupera entradas caducadas. Tras confirmar en la extensión, puedes vaciar el historial o desactivarlo y eliminar las entradas existentes.

Copiar e insertar

Copiar coloca la contraseña seleccionada en el portapapeles del sistema. Su acceso y cualquier sincronización del portapapeles del sistema dependen de macOS y de tus ajustes. Insertar envía únicamente la contraseña seleccionada al campo editable que elegiste en la página actual. QuietPass no envía formularios ni recopila el contenido de las páginas.

Solicitudes de soporte

Si escribes al soporte, el desarrollador recibe tu dirección de correo y la información que decidas incluir. Se utiliza para responder y resolver tu solicitud, y se conserva solo el tiempo necesario para ese fin y para cumplir las obligaciones aplicables. Para consultas sobre un mensaje o su eliminación, escribe a max.borzov@me.com. No se necesitan contraseñas para prestar soporte.

Este sitio web

Estas páginas no contienen scripts de análisis ni formularios de envío y están alojadas en GitHub Pages. GitHub registra las direcciones IP de los visitantes por motivos de seguridad; su tratamiento de los datos del sitio se describe en la declaración de privacidad de GitHub. Abrir la extensión no visita automáticamente este sitio.

Cambios y contacto

Esta política se actualizará si cambian las prácticas de datos de QuietPass. La fecha anterior identifica esta versión. Para preguntas sobre privacidad, contacta con max.borzov@me.com.
