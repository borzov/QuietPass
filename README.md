# QuietPass

Генератор случайных паролей для Safari на macOS 15 и новее. Приложение macOS устанавливает расширение; генерация, конфигуратор и история находятся в его окне в Safari.

## Использование

1. Откройте QuietPass.app.
2. Нажмите «Открыть настройки Safari» и включите QuietPass. Настройки также доступны через Safari → Настройки → Расширения.
3. Нажмите значок ключа в панели Safari. При каждом открытии появляется новый основной пароль и пять дополнительных.
4. Выберите длину, сложность, спецсимволы и дефис. Изменения запоминаются автоматически.
5. Скопируйте пароль или выберите редактируемое поле на странице, откройте QuietPass и нажмите «Вставить». Расширение не отправляет формы.

После успешной вставки и обработки истории окно генератора закрывается. Если вставка или сохранение истории не удались, окно остаётся открытым и показывает причину.

Открытие генератора не запускает нативный обработчик истории и не читает Связку ключей. История и её срок хранения загружаются при переходе в историю или настройки; после копирования и вставки запись сохраняется сразу. Срок хранения появляется в нижней строке после ответа хранилища.

Приложение QuietPass служит для включения расширения: оно не отображается в Dock и переключателе приложений, завершается при закрытии своего окна или после открытия настроек Safari. Для работы расширения держать приложение запущенным не требуется. Сам файл QuietPass.app должен оставаться установленным.

Длина — от 8 до 64 символов, включая разделители. При включённом дефисе пароль состоит из трёх непустых групп с двумя дефисами; размеры групп отличаются максимум на один символ.

| Сложность | Основной набор |
| --- | --- |
| Простой | Строчные латинские буквы |
| Стандартный | Строчные латинские буквы и цифры |
| Сложный | Строчные, прописные латинские буквы и цифры |

Спецсимволы `!@#$%&*?` включаются отдельно. В каждом пароле присутствуют все выбранные классы символов. Шесть значений генерируются независимо и различаются внутри набора. Глобальная уникальность за всё время работы не гарантируется.

## История и конфиденциальность

В историю попадают только успешно скопированные или вставленные пароли. Неиспользованные значения остаются в памяти окна расширения. Повторное копирование записи из истории не создаёт новую запись.

История хранится локально в Связке ключей macOS отдельно для каждого профиля Safari. Адреса сайтов, логины и история посещений не собираются. Пароли не записываются в `browser.storage.local`, не синхронизируются через iCloud и не передаются на сервер. В браузерном хранилище находятся только параметры генерации.

Срок хранения: «Не сохранять», 1, 7, 30 или 90 дней; стандартный срок — 7 дней. Срок считается от времени использования пароля и применяется ко всем записям. Просроченные записи скрываются и удаляются при следующем обращении к хранилищу. Когда Safari закрыт, отдельная служба удаления не запускается. Увеличение срока не восстанавливает уже просроченные записи.

Отключение или очистка истории требует подтверждения внутри расширения. Удаление необратимо. Если копирование или вставка прошли, а сохранить пароль не удалось, расширение сообщает об этом отдельно и не повторяет действие.

В приватных окнах доступны генерация и копирование; история и автоматическая вставка отключены. Вставка также недоступна на служебных страницах Safari, в защищённых/неподдерживаемых полях и фреймах без доступа. Если поле нельзя определить однозначно, расширение предлагает копирование.

## Устройство проекта

- `Extension/Resources/` — Manifest V3, генератор, окно, маршрутизация запросов и вставка через Safari scripting API. Веб-интерфейс не имеет runtime-зависимостей.
- `Native/` — протокол нативных сообщений, правила хранения и Keychain. Идентификатор профиля берётся из контекста Safari, а не из JavaScript-запроса.
- `App/` — небольшое SwiftUI-приложение для включения расширения.
- `Shared/Localizable.xcstrings` — общие переводы нативного приложения и обработчика истории.
- `Tests/` — Node/DOM и Swift-тесты. jsdom используется только для тестов.
- `project.yml` — исходная конфигурация XcodeGen; сгенерированный `.xcodeproj` не хранится в Git.

## Сборка

Нужны Xcode, XcodeGen, Node.js 22+ и действующая локальная подпись Apple Developer. Зависимости Swift не загружаются. В `project.yml` задана команда подписи текущего разработчика; при использовании другой учётной записи измените `DEVELOPMENT_TEAM`.

```sh
npm ci --ignore-scripts
npm test
swift test
xcodegen generate
xcodebuild -project QuietPass.xcodeproj -scheme QuietPass -configuration Debug -derivedDataPath /tmp/QuietPassBuild build
```

Готовое приложение: `/tmp/QuietPassBuild/Build/Products/Debug/QuietPass.app`. Запустите его и включите расширение в Safari. Не нужно разрешать неподписанные расширения или отключать защиту Safari.

Проверка подписи:

```sh
codesign --verify --deep --strict /tmp/QuietPassBuild/Build/Products/Debug/QuietPass.app
```

Тест реального Keychain по умолчанию пропускается. Для его запуска используйте:

```sh
QUIETPASS_RUN_KEYCHAIN_TESTS=1 swift test
```

Тест создаёт отдельный временный сервис с UUID и удаляет собственную тестовую запись. Рабочую историю расширения он не читает.

При необходимости обновить иконки:

```sh
swift scripts/generate-icons.swift
```

Если приложение копируется из DerivedData в постоянный каталог, не оставляйте в Safari зарегистрированными две копии одного расширения. Приложение для повседневного запуска следует держать в одном постоянном месте.

## Локализация

Поддерживаются русский, английский, упрощённый китайский, немецкий, французский и испанский. Язык выбирается системой локализации Safari/macOS; резервный язык — английский. Даты в истории форматируются для языка интерфейса.

Строки расширения находятся в `Extension/Resources/_locales/<locale>/messages.json` и доступны через `browser.i18n`. Это [стандартная структура Safari Web Extensions](https://developer.apple.com/documentation/safariservices/creating-a-safari-web-extension). Нативные строки находятся в `Shared/Localizable.xcstrings`, который включён в оба целевых модуля Xcode.

Для добавления языка создайте его каталог на основе `_locales/en/messages.json`, переведите значения `message`, сохранив ключи и подстановки `$LENGTH$`, `$COUNT$` и другие. Добавьте тот же язык в нативный каталог. У китайского используются идентификаторы `zh_CN` для расширения и `zh-Hans` для нативной части. Дополните список проверяемых языков в `Tests/Web/i18n-mock.js` и `Tests/Web/i18n.test.js`, затем выполните `npm test` и пересоберите приложение. Переводы карточки App Store настраиваются отдельно.
